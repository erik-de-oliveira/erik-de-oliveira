## Projetos Analíticos em Destaque

### 1. [Modelagem Relacional de Ativos Financeiros](https://github.com/erik-de-oliveira/simulador-fiis-relacional)
* **Escopo de Negócio:** Desenvolvimento de um simulador estruturado em arquitetura de dados tabular para projeção e análise de cenários de rentabilidade.
* **Foco Técnico:** Estruturação de banco de dados, modelagem de dados relacionais e cálculos preditivos.
* **Impacto:** Criação de um ambiente de dados escalável para simulações complexas de longo prazo.

### 2. [Sistema de Controle e Tratamento de Dados Fiscais](https://github.com/erik-de-oliveira/controle-impostos-renda)
* **Escopo de Negócio:** Estruturação de controle de dados voltado para conformidade (compliance) e declarações tributárias.
* **Foco Técnico:** Limpeza, validação, consolidação e cruzamento de bases de dados para garantir a integridade da informação reportada.
* **Impacto:** Eliminação de inconsistências no reporte de dados financeiros através de auditoria e padronização de registros.
